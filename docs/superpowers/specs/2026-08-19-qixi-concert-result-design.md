# 七夕演唱会结果页设计

## 目标

将现有拆礼物流程的最终结果页替换为“新裤子巡回演唱会广州站”双人邀请。页面需要同时传达三件事：演唱会现场氛围、已经准备好两张票、邀请花花一起赴约。

## 核心文案

- 英文氛围标题：`NEW PANTS`、`LIVE!`
- 票根标签：`TWO TICKETS · ONE NIGHT`
- 演出名称：`新裤子巡回演唱会广州站`
- 时间：`2026.08.22 · SAT · 19:30`
- 场馆：`宝能广州国际体育演艺中心`
- 人数：`ADMIT TWO`
- 邀请语：`花花，8月22日周六，和我一起去看新裤子吧。`
- 补充文案：`为我们准备了两张相邻的票。`
- 默认按钮：`当然要一起 ♥`
- 回应后按钮：`说好了，现场见 ♥`

## 页面结构

结果页为单列手机布局，包含四层：

1. 现场照片作为上半屏全幅主视觉，保留舞台、灯束和彩带。
2. 主视觉上叠加像素风 `NEW PANTS`、荧光绿 `LIVE!` 和三颗星光，提取官方海报的摇滚与故障拼贴语言。
3. 一张轻微倾斜的双人票根压在现场图与黑色邀请区之间。票根左侧展示演出名称、时间和场馆，右侧用荧光绿色票尾展示 `08.22` 与 `ADMIT TWO`。官方海报以小型拍立得贴纸形式压在票根右上角。
4. 黑色邀请区展示日期标识、邀请语、补充文案和回应按钮。

## 视觉语言

- 主背景为接近纯黑的暖黑色，承接现场照片的金色灯光。
- 重点色使用官方海报中的荧光绿；红色和蓝色只用于像素标题的错位阴影。
- 票根使用暖白纸张色，避免整页过暗，同时与现有拆礼物页面的米白色形成呼应。
- 中文邀请语使用宋体风格，维持前面七夕页面的浪漫感；英文标题与日期使用等宽像素风格，建立演唱会气氛。
- 现场照片和海报均使用用户提供的原图，不生成或改写演出信息。

## 回应交互

按钮不产生页面跳转，也不提交或保存任何信息。

默认状态为白色胶囊按钮，带黑色柔和投影、荧光绿底部投影和轻微内阴影，表现为悬浮的实体按钮。点击后执行一次性反馈：

1. 按钮在约 160ms 内下压并轻微缩小。
2. 按钮在约 250ms 内变为荧光绿，文案切换为 `说好了，现场见 ♥`。
3. 爱心、星光和少量红绿彩带从按钮周围扩散，约 800ms 后淡出。
4. 动效结束后保留已回应状态；重复点击可以重新播放轻量反馈，但不会跳转到其他页面。

## 资源与隐私

- 正式页面只使用用户提供的演唱会海报和现场照片。
- 订单截图不直接展示，不写入网页资源，避免暴露身份证尾号、票价、费用和退款入口。
- 演出信息从订单截图和海报中提取后作为页面文字展示。
- 若图片加载失败，页面仍显示黑色渐变背景、完整票根信息和邀请按钮，流程不会中断。

## 状态与数据流

现有问卷和拆礼物状态保持不变。礼盒揭晓后进入新的演唱会结果页；回应按钮只在结果页内部维护一个 `responded` 视觉状态，不修改问卷答案，也不影响“再看一次”逻辑。

“再看一次”入口继续保留，但视觉弱化为结果页底部的文字按钮。触发后返回礼盒等待页，允许完整重播揭晓流程。

## 验证标准

- 在 390 × 844 手机视口中，现场图、完整票根、邀请语和回应按钮能够按顺序阅读，不发生水平溢出。
- 邀请语必须包含“8月22日周六”。
- 默认按钮与回应后按钮文案准确。
- 点击回应按钮不导航、不刷新页面，反馈动效完整播放。
- 点击“再看一次”仍能返回礼盒页。
- 页面没有控制台错误，所有现有自动化测试继续通过，并为新结果页文案、资源和回应状态补充测试。
