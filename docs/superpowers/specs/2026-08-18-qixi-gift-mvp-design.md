# 七夕拆礼物 H5 MVP 设计

## 目标

为女友“何花花”制作一个手机端优先的七夕惊喜页面。用户通过三道没有正确答案的单选题逐步进入礼物页，点击礼盒后看到叠放门票，完整跑通“进入氛围—参与互动—拆开惊喜”的流程。

## 页面与交互

### 1. 首页

- 标题：`何花花的第一个七夕。`
- 副标题：`抱着刻有你名字的黑色玫瑰，我们出发吧`
- 一个主按钮进入问卷。
- 页面采用暖白、深酒红和柔金色，配合黑色玫瑰意象；不加入音乐、登录、分享或后台能力。

### 2. 问卷页

- 顶部显示当前题目进度，范围从 `1 / 3` 到 `3 / 3`，进度条同步增长。
- 每次只显示一道题。
- 所有选项都没有对错；点击任一选项后短暂显示选中态，再进入下一题。
- 保留返回上一题的能力，返回后显示之前的选择。
- 问题与选项：
  1. `你是谁？`：`黄婷`、`何威龙老婆`
  2. `《乐队的夏天》中，哪个组合你最想和男朋友去一次？`：`本拉登`、`新裤子乐队`、`披投士`
  3. `你老公是谁？`：`何威龙`、`何威龙`、`何威龙`

### 3. 礼物页

- 完成第三题后出现礼物盒和“点击拆开”提示。
- 点击礼盒后，盒盖抬起、礼盒淡出，并出现轻量粒子和光晕效果。
- 动效完成后显示一张叠放门票的本地静态 SVG 图。
- 提供“再看一次”按钮，回到未拆开的礼盒状态；不清空问卷答案。

## 技术结构

- 使用原生 HTML、CSS 和 JavaScript，无运行时框架和第三方依赖。
- `index.html` 负责页面骨架与入口。
- `src/app.js` 保存问题数据、状态转换和渲染逻辑。
- `src/styles.css` 负责移动端布局、基础视觉和动效。
- `public/tickets.svg` 是可替换的静态门票图。
- `tests/app.test.mjs` 使用 Node 内置测试运行器验证流程状态，不依赖浏览器框架。

## 状态与异常处理

- 页面状态只有 `home`、`quiz`、`gift`、`revealed` 四种。
- 问卷索引始终限制在 0 到 2；没有选择时不会越过当前题。
- 连续快速点击选项只触发一次前进，避免跳题。
- 动画执行期间礼盒按钮禁用，避免重复触发。
- 尊重系统的“减少动态效果”设置，关闭大幅移动动画但保留状态变化。

## 验收标准

- 在手机宽度和桌面浏览器中均可完整完成：首页 → 三道单选题 → 礼物盒 → 门票。
- 每个选项都能进入下一题，不显示正确或错误。
- 进度文本和进度条与题目同步。
- 返回上一题时保留已选答案。
- 礼盒只能触发一次拆开流程，“再看一次”能够重置礼物状态。
- 页面全部资产来自本地，断网后仍可运行。
